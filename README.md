# Event Website

Build a premium, modern, fully responsive startup event website for "BM Investment 2026 – Pitch Summit".

Use the attached image ONLY as a reference for the website flow and information architecture. Do NOT copy its old UI/dashboard style.

DESIGN:

Create a clean, premium 2026 startup/technology conference aesthetic.

Professional, modern, investor-friendly, spacious and visually impressive.

Avoid clutter, excessive glassmorphism, excessive gradients, neon effects, and dashboard-like small boxes.

COLORS:

Primary Blue: #3B82F6

Accent Yellow: #FBBF24

Light Background: #FEFCE8

Dark Background: #0F172A

Dark Cards: #172033

White: #FFFFFF

Text: #0F172A

Dark Text: #F8FAFC

Muted: #64748B / #94A3B8

Use blue as the main brand/action color and yellow only as a controlled accent.

THEMES:

Support both Light and Dark mode with a theme toggle.

Both themes must feel like the same brand.

SECTIONS:

1. Sticky Navbar + Register CTA + theme toggle

2. Hero — BM Investment 2026, strong headline, date, location, Register CTA

3. Event statistics

4. About the Event

5. How It Works

6. Startup Tracks

7. Pitch Format & Rules

8. Judges

9. Event Schedule

10. Venue + Map

11. FAQ accordion

12. Final Registration CTA

13. Footer

Keep the same overall flow as the reference image, but redesign it as a real premium landing page rather than a UI-flow diagram.

RESPONSIVE:

The website must be fully responsive and intentionally designed for:

- Desktop

- Laptop

- Tablet

- Mobile (320px+)

Do NOT simply shrink the desktop version.

Desktop:

Multi-column layouts and horizontal timeline.

Tablet:

2-column layouts where appropriate.

Mobile:

Single-column layouts, touch-friendly buttons, vertical timeline, mobile hamburger navigation, readable typography, properly sized images and cards.

There must be NO horizontal scrolling, overlapping elements, clipped text, or broken layouts.

WEB + MOBILE:

The same codebase/design system must work beautifully on web and mobile.

Make the experience feel app-like on mobile and structure it so it can later be extended into a PWA/mobile app.

INTERACTIONS:

Add smooth scrolling, subtle section animations, button/card hover states, FAQ accordion animation, theme transition, and elegant timeline animations. Keep animations subtle and professional.

QUALITY:

Use strong typography, generous whitespace, consistent 12–16px card radius, refined borders/shadows, accessible contrast, optimized images, and fast performance.

FINAL FEEL:

It should look like a real premium 2026 startup pitch summit website for founders, investors, mentors and judges — polished, trustworthy, modern and launch-ready.
